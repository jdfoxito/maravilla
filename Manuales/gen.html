BLOQUE 4 — Pruebas de conectividad de red (enviar TODAS las salidas)

4.1 Resolución de nombres de los nodos Oracle

4.2 Puerto 1521 hacia las bases de datos (origen sriapp44 10.2.2.218)

nc -z -w5 10.2.3.64 1521 && echo "sri23v 1521 OK" || echo "sri23v 1521 FALLA (revisar firewall)"

nc -z -w5 10.2.3.62 1521 && echo "sri22v 1521 OK" || echo "sri22v 1521 FALLA (revisar firewall)"

4.3 Puerto 445 hacia los fileservers (montajes CIFS)

nc -z -w5 10.2.0.103 445 && echo "fileserver 10.2.0.103 445 OK" || echo "10.2.0.103 445 FALLA (revisar firewall)"

nc -z -w5 10.1.0.100 445 && echo "ftps 10.1.0.100 445 OK" || echo "10.1.0.100 445 FALLA (revisar firewall)"

4.4 Puerto adicional (otro proyecto del área)

nc -z -w5 192.168.72.64 5432 && echo "192.168.72.64 5432 OK" || echo "192.168.72.64 5432 FALLA"
Alternativa sin nc (método nativo de bash, mismo resultado):
timeout 5 bash -c "echo >/dev/tcp/10.2.3.64/1521" && echo "PUERTO OK" || echo "FALLA"

BLOQUE 7 — Instalación de Python 3.13.5 (compilado desde fuente)

7.1 Obtener el código fuente

cd /usr/src

# OPCIÓN B — Sin Internet (Producción): copiar el archivo desde el servidor de Desarrollo:

# (desde una máquina con acceso a ambos, o scp directo si hay ruta)

# El archivo está en: 10.12.4.94:/home/python/Python-3.13.5.tgz

# Dejarlo en /usr/src/Python-3.13.5.tgz

7.2 Descomprimir y configurar (parámetros CRÍTICOS del proyecto)

cd /usr/src

sudo tar xzf Python-3.13.5.tgz

cd Python-3.13.5



sudo ./configure --prefix=/usr/local/python3.13 \

    --enable-shared \

    --enable-optimizations \

    --with-computed-gotos \

    --with-openssl=/usr \

    --with-openssl-rpath=auto \

    LDFLAGS="-Wl,-rpath /usr/local/python3.13/lib"

7.3 Compilar e instalar (sin sobrescribir el Python del sistema)

sudo make -j $(nproc)

sudo make altinstall

La compilación con --enable-optimizations toma varios minutos (es normal).

7.4 Registrar librerías compartidas y compatibilidad libffi

echo "/usr/local/python3.13/lib" | sudo tee /etc/ld.so.conf.d/python313.conf

sudo ldconfig



# Compatibilidad libffi para RHEL 10:

if [[ ! -f /usr/lib64/libffi.so.6 ]]; then

  libffi=$(find /usr/lib64 -name "libffi.so.*" | head -1)

  if [[ -n "$libffi" ]]; then

    sudo ln -sf "$libffi" /usr/lib64/libffi.so.6

    sudo ldconfig

  fi

fi

7.5 Crear los alias oficiales del proyecto
